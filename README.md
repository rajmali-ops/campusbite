# CampusBite — Smart College Canteen System

A 100% web-based, zero-installation canteen order and queue management system with counter ordering, automatic stock deduction, student unique ID matching, and a fullscreen public TV display for secondary HDMI monitors.

## Quick Links
- **Student Web Portal:** `http://localhost:3000/`
- **Staff POS & Kitchen:** `http://localhost:3000/staff` (Protected by Staff Master PIN: `1234`)
- **Public TV Board (HDMI):** `http://localhost:3000/tv`

## Key Capabilities
- **Zero App Download:** Pure web application that runs directly in any mobile or desktop browser.
- **Staff Terminal Security Lock:** Protected with a 4-digit Master PIN (`1234`), quick touch numpad, and instant "Lock Terminal" button.
- **Offline Counter Ordering:** Students quote their permanent ID (e.g. `CB-1042`); staff punches the order.
- **Automatic Stock Deduction:** Quantities decrement automatically on order confirmation.
- **Anti-Theft Pickup PIN:** Each order generates a secret 4-digit PIN verified by staff on collection.
- **Dual-Monitor / HDMI Support:** 1-click launch from POS directly onto connected canteen TV screens with Web Audio chimes.
